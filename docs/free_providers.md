# 正规免费额度：用了哪些、还能接哪些（2026-10-19）

原则：**每家服务商注册一个账号**，用官方提供的免费层。下面这些都不做：
- 多开账号
- 换 IP 绕过限额
- 用别人泄露的 key
- 走来源不明的中转

数据来源：FreeLLMAPI 自带的模型目录（`server/data/freeapi.db` 的 models 表，只读查询）。额度会变，以官网为准。

暂不建议：
- ModelScope：只限非商业用途，每天要登录领额度
- 来源不明的聚合 / 中转，比如目录里免费提供 Claude、GPT 的几家，以及标明会记录流量的服务：来源和数据去向都不清楚，**不用来处理代码**
  - 例如 **LLM7.io**：不用 key、匿名就能调，但 2026-10-19 的模型列表里有 claude-opus-5-5、gpt-6 等付费模型，免费转售付费模型多半违反原厂条款，属于灰色中转，不接
- Aion Labs（每天 2 万 token）、Hugging Face（每月 0.1 美元额度）：额度太小，不值得接

## 怎么接

1. 你自己去官网注册，拿到 key。**agent 不替你注册，也不替你填 key**
2. 打开 Mac 上的 FreeLLMAPI 后台（`http://127.0.0.1:3001`），把 key 加进对应平台
3. FreeLLMAPI 会自动轮换、失败换下一家；iu 的路由（`~/.infiniteusage/routes.json`）可以重新跑能力画像，把新模型排进去
