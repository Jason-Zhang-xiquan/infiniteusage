# 阶段 A 结果（2026-10-18）——门槛通过

计划见 [PLAN_offload_v1.md](PLAN_offload_v1.md)。阶段 A 只在临时项目里用了几次 Haiku，没有改全局配置。

## A1 兜底 + 护栏（`iu/det.py`、`iu/offload.py`）

- `iu sum` 等免费模型最多 30 秒（`--budget`）。失败、限流、超时就改用规则过滤，退出码和原命令一致
  - 实测：把 FreeLLMAPI 指到一个打不开的端口，拿到的是规则过滤的结果，退出码 1，3 个失败的位置都在
- **新增护栏**（实测发现 `auto` 有时会被路由到弱模型，漏掉位置、改写报错原文）：
  - 摘要里出现原始输出中**不存在的「文件:行」** → 整份丢掉，改用规则过滤
  - 原始输出里的关键报错行（Error / Exception / FAIL / TS 错误码 / ERR! 等）在摘要里没有原样出现 → 自动原样补在后面
- 命令在 bash 里执行：Windows 上 Claude Code 的 Bash 是 Git Bash 语法，不能用 cmd 跑

基准里加了「auto + 护栏」一组（30 次）：命中 91%，编造 0，失败 0，延迟中位 4 秒 / P95 7 秒。
这一轮免费池的状态不一样：OVH 的额度已被前一轮基准用掉，30 次里有 19 次被路由到较弱的 `kilo/dots-3`；前一轮 28/30 走的是 `ovh/Qwen3.8-27B`，命中 97%。
**结论：不能只用开放的 `auto`。正式启用前要配一条固定的强模型链**（Qwen3.8 → Qwen3.6 → Groq，都不行再用规则过滤）。

## A2 hook 处理程序（`iu/hook.py`，单元测试 `tests/test_hook.py`：9 个全过，Windows 和 Mac 都通过）

同时满足下面几条才改写，否则原样放行：
- 工具是 Bash，且不是后台命令
- 命中白名单：测试、类型检查、lint、构建、git log/diff/show/blame/grep、rg/grep/find
- 不是 install、push 之类会改环境的命令
- 没有自己用 head/tail 截过输出
- 当前目录在试点名单里，且没有 `.iu-private`

不设置 permissionDecision；出任何错都原样放行；每次改写记录到 `~/.infiniteusage/hook.jsonl`。

## A3 Codex 额度权重校准（`bench/calibrate_codex.py`）

14 天、9523 次请求、216 个「已用 % 上升」样本：

| token 类型 | 百万 token | 每百万占周额度 | 贡献 |
|---|---|---|---|
| 未缓存输入 | 35.6 | 1.66% | 32% |
| 缓存读 | 1512 | 0.06% | 49% |
| Sol 输出 | 6.1 | 0（拟合不出来） | 0% |
| Astra 输出 | 0.5 | 80% | 20% |

**结论只能当方向参考：**

- 拟合合计 187%，实际 266%，有约 30% 解释不了。可能是本机日志里看不到的用量（云端任务、其他设备）
- 留出检验误差 26%
- Sol 的输出和缓存读总是同时增减，数据分不开，所以 Sol 输出的权重算成了 0。**「降 effort 能省多少」目前还量不准**
- 比较稳的结论：在这段数据里，Codex 额度主要花在**上下文**（缓存读 + 未缓存输入，约 80%），不是输出。所以压缩上下文对 Codex 也是主要杠杆

（修了一个 bug：多个会话的额度快照新旧不一，数字会来回跳，一开始被重复计算成 +443%。现在只认超过本窗口历史最高值的部分。）

## A4 hook 小测（Mac，Claude Code 2.1.283，临时项目 `/tmp/iu_spike`，Haiku）

| 问题 | 结果 |
|---|---|
| ① `updatedInput` 生效吗 | ✅ Claude 发出 `python3 -m unittest test_big -v`，实际执行的是 `iu sum`。工具结果 970 字符（原始 19,226 字符），Claude 的回答完全正确（3 个失败、6 个行号、退出码 1），没有多跑命令 |
| ② 会不会绕过权限确认 | ✅ 不会。Claude Code 按**改写后**的命令检查权限：只允许原命令时，改写后的命令被拦下（"This command requires approval"）。**副作用**：你现有的「自动允许 npm test」这类规则不再匹配，会多一些确认弹窗，阶段 C 前要定怎么处理 |
| ③ 退出码保留吗 | ✅ "Exit code 1"，被标成错误 |
| ④ 你看得到改写吗 | ⚠️ 显示的命令还是原命令。只能从输出开头的 `[iu 免费模型 …]` 看出走了外包 |
| 额外：hook 自己坏了会怎样 | ❌→✅ Claude Code 把 hook 退出码 2 当作「拦截」。脚本不存在时 Python 正好退出码 2，**所有 Bash 命令都会被拦**。在命令后面加 `\|\| true` 以后，坏掉的 hook 原样放行。**正式安装必须带 `\|\| true`** |

花费：4 次 Haiku 运行，第一次约 $0.025（API 等价），合计可以忽略。

## 门槛

A4 证明了三件事：hook 能改写命令、不会绕过权限确认、退出码正确。**门槛通过 → 进入阶段 B。**
